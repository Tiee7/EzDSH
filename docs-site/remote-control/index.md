# 远程控制

远程控制功能让你通过即时通讯平台向 DSH 发送命令。当前首先支持 **飞书**，在设置中对应「飞书控制」。

## 配置步骤

### 1. 创建飞书自建应用

1. 打开[飞书开放平台](https://open.feishu.cn/)；
2. 创建 **企业自建应用**；
3. 启用 **机器人** 能力；
4. 申请以下权限：
   - `im:message:send_as_bot`
   - `im:message.p2p_msg:readonly`（私聊）
   - `im:message.group_msg:readonly`（群聊，可选）
5. 发布应用到你的企业；
6. 复制 **App ID** 和 **App Secret**。

### 2. 配置飞书事件订阅

在飞书应用后台：

1. 进入 **事件订阅**；
2. 选择 **使用长连接接收事件**；
3. 添加事件类型：
   - `im.message.receive_v1`
4. 保存。

不需要请求地址、ngrok 或防火墙规则。

### 3. 配置 EzDSH

打开 EzDSH → **设置 → 飞书控制**。

| 字段 | 说明 |
|---|---|
| 启用飞书控制 | 开启 |
| DSH 会话 ID | 可选。留空则首次使用时自动创建；或粘贴现有会话 ID 与图形界面共享。 |
| 单轮等待超时（毫秒） | `300000` —— 等待一轮 DSH 任务的最大时间。 |
| 状态更新间隔（毫秒） | `60000` —— 任务运行期间发送进度更新的频率。 |
| 白名单用户 Open ID（每行一个） | 你的飞书 `open_id`。 |
| App ID | 来自第 1 步。 |
| App Secret | 来自第 1 步。 |

点击 **保存**。

### 4. 配对飞书账号

不需要手动查找 `open_id`，可以使用验证码配对：

1. 在 EzDSH 中进入 **设置 → 飞书控制**；
2. 填写飞书 **App ID** 和 **App Secret**；
3. 点击 **开始配对**；
4. EzDSH 显示一个 6 位验证码并开始 5 分钟倒计时；
5. 在私聊中把该验证码发给飞书机器人；
6. EzDSH 会自动把你的 `open_id` 加入白名单并回复「配对成功，已加入白名单。」。

只有私聊消息可以完成配对，验证码 5 分钟后过期。

### 5. 发送命令

在机器人所在的飞书群聊或私聊中发送：

```
2 + 2 等于多少
```

机器人会立即确认任务，在配置的 DSH 会话中执行，并在任务完成后回复最终答案。运行期间会根据 **状态更新间隔** 设置周期性地发送进度更新。

## 安全说明

- 事件通过飞书的外发 WebSocket 接收，不向公网开放本地端口；
- 只有白名单中的飞书用户才能触发命令；
- 命令在配置的 DSH 会话中执行，与图形界面会话共享状态；
- 凭据文件以 `0o600` 权限保存。

::: warning 注意
白名单用户可以在 DSH 会话中执行任意操作，请只添加可信的用户。
:::

## 配置文件

配置保存在 EzDSH 数据目录的 `channel-bridge.json` 中：

```json
{
  "enabled": true,
  "sessionId": "your-session-id",
  "sessionTimeoutMs": 300000,
  "statusIntervalMs": 60000,
  "allowList": ["ou_xxxxxxxx"],
  "timeoutMs": 120000,
  "feishu": {
    "appId": "cli_xxxxxxxx",
    "appSecret": "xxxxxxxx"
  }
}
```
