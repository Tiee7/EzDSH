# 下载与更新

## 下载安装包

从 GitHub Releases 页面下载对应平台的安装包：

| 平台 | 安装包 |
|------|--------|
| macOS（Apple Silicon） | `.dmg` |
| Windows（x64） | `.exe` 安装程序 |

请从发布版的附件列表下载。**不要**下载 GitHub Actions 页面里的 Artifacts——它们被统一打包成 ZIP，是 CI 构建归档，不是安装入口。

## 自动更新

EzDSH 会在后台自动检查更新。发现新版本时，应用会提示你，确认后即可在应用内完成更新。

### 更新会丢数据吗

**不会。** 更新只替换客户端和内置的 AI 运行时，不会删除你的：

- 配置
- 会话
- Profile
- Plugin
- 日志
- 本地工作数据

更新后无需重新配置，直接继续使用即可。

## 更新失败怎么办

如果更新没有自动进行或失败了：

1. 关闭应用后重新打开，再次触发更新检查；
2. 确认网络可以正常访问更新服务；
3. 仍然失败的话，也可以直接到 GitHub Releases 手动下载最新安装包覆盖安装（用户数据不受影响）。
