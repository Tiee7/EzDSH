# 首次使用

## 打开应用后会发生什么

第一次打开 EzDSH 时，应用会自动完成这些事情：

1. 在你的电脑上创建本地数据目录；
2. 启动内置的 DeepSeek Harness 运行时；
3. 对本地运行时做健康检查，确认就绪；
4. 加载 Harness 工作界面。

全程不需要命令行，也不需要手动管理端口或服务。

## 看到网页界面，该做什么

你看到的界面是 DeepSeek Harness 的 Web UI（工作空间）。如果还没有配置模型供应商，界面会提示你进行配置。

### 1. 选择模型供应商

在配置里选择一家供应商，例如：

- **DeepSeek**（官方直连）
- **OpenAI**、**Anthropic**、**Google Gemini**
- **Moonshot / Kimi**、**Kimi Code**、**MiniMax**、**Z.AI / GLM**
- **Mistral**、**OpenRouter**、**Groq**、**Together AI**
- **火山引擎（Volcano Engine）**

### 2. 填写 API key

把你在对应平台申请的 API key 粘贴到输入框并保存。还没有 key 的话，可以看看[常见问题里的说明](../faq#api-key-是什么-我在哪里可以获得)。

### 3. 开始会话

配置完成后，新建一个会话开始提问。你的会话会自动保存在本地，关闭应用再打开后依然在。

## 数据存在哪里

EzDSH 是本地优先的应用。API key、会话、Profile、Plugin 和日志都保存在你自己电脑的本地目录里，不会上传到云端。

如果之后遇到启动异常或白屏等问题，可以参考[常见问题中的故障排查](../faq#故障排查)，或者在设置里打开运行日志查看原因。
