# 国内免费获取 Tokens 攻略

> 最后更新：2026‑08
>
> 以下均为官方正规渠道，需要实名认证，仅供个人测试学习使用。

免费额度通常分两类：

1. **新用户一次性新人包**（有有效期）；
2. **永久 / 每日重置免费层**（一般有 QPS / 并发限制）。

::: danger 重要提示
第三方私钥、共享 Token 属于违规，不要使用。
:::

- **新人**：注册实名送 2000 万 token（一次性）
- **永久免费层**：GLM‑4‑Flash、GLM‑4.7‑Flash 永久免费，128K‑200K 上下文，并发 30
- **有效期**：新人包永久；Flash 系列长期免费
- **入口**：[open.bigmodel.cn](https://open.bigmodel.cn) 控制台

### 2. 火山引擎 · 火山方舟（字节豆包 API）

- **新用户安心体验包**：每个模型 50 万 token 一次性
- **协作奖励计划**：每日可领 200 万 token（按天刷新）
- **模型**：豆包 Seed 全系、DeepSeek 等
- **备注**：必须实名认证；豆包网页版 / App 对话不提供 API token，API 仅火山方舟输出

### 3. MiniMax（稀宇）

- 实名后赠送 15 元代金券，等价免费 token，有效期约 2 个月
- 适合语音、视频、多模态调用

### 4. 讯飞星火开放平台

- 新用户实名领取 500 万 token 新人包，Spark X2 系列，有效期限时

## 四、获取免费 Token 的通用规则

1. **必须实名认证**：几乎所有国内 API 平台领取免费额度都要求实名，不实名拿不到免费 token。
2. **新人包每个账号只能领一次**，多账号薅福利属于违反用户协议。
3. **永久免费模型 ≠ 无限制**，一般有 QPS、并发上限，不适合生产环境。
4. **App / 网页对话免费 ≠ API 免费**：豆包 App、Kimi 网页免费聊天，不等于 API 接口免费。

## 五、避坑提醒

- ❌ 网上售卖、分享现成 token、共享 key、破解额度均违规，极易泄露密钥、产生巨额账单，不要使用。
- 所有免费额度仅限学习、原型测试，正式业务需要购买付费资源包。
