# 短视频内容运营 V1 设计

**日期：** 2026-08-29

**状态：** 已完成场景确认，等待书面规格确认

**依赖：** `2026-08-29-workflow-centric-product-design.md`

## 1. 目标

EZDSH 每天在无人值守状态下完成短视频选题、调研、文案和审核，用户早上打开控制中心时可以直接审批结构化内容成果。

V1 用真实运营任务验证工作流、员工、AI 处理、JSON 契约、有限返工、人工审批、定时触发、持久化运行和候选经验。V1 不自动发布内容到外部平台。

## 2. 使用前配置

用户为一个内容项目配置：

- 账号名称和平台；
- 账号定位、目标人群和核心主题；
- 品牌语气、禁用表达和合规要求；
- 视频目标时长和常用内容结构；
- 参考资料、产品资料和历史内容；
- 每日需要生成的选题数和脚本数；
- 定时执行时间；
- 单次运行的时间、模型调用和费用预算；
- 审批人和告警方式。

这些信息属于项目知识，不复制成员工长期记忆。

## 3. 执行角色

### 3.1 选题策划员工

- 根据账号定位、受众和近期内容生成候选选题；
- 说明目标受众、核心冲突、内容角度和预期价值；
- 避免与近期已发布内容重复；
- 不编造热点事实或平台数据。

### 3.2 调研员工

- 为入选选题补充事实、案例、数据和来源；
- 区分事实、推断和创作建议；
- 无法验证的信息必须标记为未知；
- 输出可供文案员工引用的结构化素材包。

### 3.3 文案员工

- 将选题和素材包转为适合目标平台的短视频脚本；
- 输出开头钩子、正文、行动号召、字幕建议和时长估算；
- 遵循品牌语气、禁用表达和平台限制；
- 不将未经验证的推断写成事实。

### 3.4 内容审核员工

- 检查选题价值、开头吸引力、逻辑、事实、品牌一致性和风险；
- 输出逐项评分、问题清单和通过决定；
- 对可修复问题返回明确修改要求；
- 对事实缺失、敏感内容或冲突信息升级为人工处理。

## 4. 工作流

```text
每日定时触发
→ 读取项目配置、近期内容和待避重复项
→ 选题策划员工生成候选选题
→ AI 处理进行格式校验、评分汇总和去重
→ 选择排名靠前且风险可接受的选题
→ 调研员工并行补充素材
→ 文案员工生成脚本
→ 内容审核员工审核
→ 未通过且可修复：返回文案员工，最多返工两次
→ 事实不足或高风险：进入人工处理
→ 审核通过：进入人工审批列表
→ 保存内容成果、运行记录和候选经验
```

单个选题的失败不应默认阻断所有其他选题。并行分支独立记录结果，最终汇总节点列出成功、失败和待人工处理项。

## 5. JSON 数据契约

### 5.1 候选选题

```json
{
  "id": "topic_001",
  "title": "候选标题",
  "audience": "目标人群",
  "angle": "内容角度",
  "hook": "核心冲突或钩子",
  "expectedValue": "用户获得的价值",
  "evidenceNeeded": ["需要验证的事实"],
  "riskTags": [],
  "scores": {
    "relevance": 0,
    "novelty": 0,
    "clarity": 0,
    "productionFit": 0
  }
}
```

### 5.2 调研素材包

```json
{
  "topicId": "topic_001",
  "facts": [
    {
      "claim": "可以用于脚本的事实",
      "sourceArtifactId": "artifact_001",
      "verifiedAt": "2026-08-29T00:00:00+08:00",
      "confidence": 0.9
    }
  ],
  "inferences": [],
  "unknowns": [],
  "creativeDirections": []
}
```

### 5.3 短视频脚本

```json
{
  "topicId": "topic_001",
  "title": "视频标题",
  "hook": "开头钩子",
  "segments": [
    {
      "order": 1,
      "voiceover": "口播内容",
      "caption": "字幕内容",
      "visualSuggestion": "画面建议",
      "estimatedSeconds": 8
    }
  ],
  "callToAction": "行动号召",
  "sourceArtifactIds": ["artifact_001"],
  "estimatedDurationSeconds": 60,
  "tags": []
}
```

### 5.4 审核结果

```json
{
  "topicId": "topic_001",
  "decision": "revise",
  "scores": {
    "hook": 0,
    "logic": 0,
    "evidence": 0,
    "brandFit": 0,
    "safety": 0
  },
  "issues": [
    {
      "type": "evidence",
      "severity": "major",
      "message": "需要修复的问题",
      "suggestedAction": "明确修改要求"
    }
  ],
  "requiresHumanReview": false
}
```

所有结构在进入下一节点前执行 Schema 验证。模型输出格式错误时允许一次结构化修复；仍然失败则该分支进入“需要处理”。

## 6. 用户体验

### 6.1 工作流模板

模板创建向导只要求用户填写业务信息，不要求理解 Agent、JSON Schema 或任务队列。高级用户可以进入画布修改节点、映射、预算和审批策略。

### 6.2 控制中心

早间成果卡片显示：

- 本次运行状态和耗时；
- 生成、通过、返工失败和待人工处理的数量；
- 每个选题的标题、评分、脚本预览和来源；
- 审核问题和修改历史；
- 费用和模型调用统计；
- 批准、退回修改和拒绝操作。

批准只表示内容可以进入后续制作流程。V1 不直接发布到短视频平台。

### 6.3 临时任务台

用户可以在临时任务台手动试做一次选题或文案，并将成熟配置保存为该工作流的草稿或项目规则。

## 7. 调度和运行

- 定时触发器只能绑定已发布工作流版本；
- 每次运行固定项目配置快照、工作流版本和员工版本；
- 定时任务采用项目时区；
- 同一项目同一工作流默认不并发运行，前一次未结束时按照配置跳过或排队；
- 运行状态和节点检查点持久化；
- 应用窗口关闭不能丢失运行状态；
- 真正跨 Mac 休眠持续执行需要始终在线的 Worker，不将其错误描述为本地休眠可运行。

## 8. 失败处理

| 情况 | 处理 |
|---|---|
| 模型或网络暂时失败 | 有限次数指数退避重试 |
| JSON 契约失败 | 一次结构化修复，之后进入需要处理 |
| 内容审核未通过 | 最多两次文案返工 |
| 事实无法验证 | 标记未知并进入人工处理 |
| 单个选题分支失败 | 保留其他分支，最终汇总失败项 |
| 预算或时间超限 | 暂停后续执行并告警 |
| 凭证或权限错误 | 不重试写操作，等待管理员处理 |
| Worker 中断 | 从已持久化检查点恢复 |

重试不得导致同一成果重复写入内容库。每个运行、选题和成果使用稳定幂等键。

## 9. 候选经验

V1 保存候选经验，不自动改变员工：

- 用户对选题和文案的批准、退回与修改意见；
- 哪些审核问题经常出现；
- 哪些项目规则缺失或冲突；
- 候选经验的来源运行、作用域、置信度和有效期。

员工长期记忆和自动版本升级属于产品第五阶段。在此之前，候选经验只供查看和人工整理。

## 10. 测试

必须覆盖：

- 各节点输入输出 Schema；
- 去重、筛选、并行调研和汇总；
- 返工次数上限；
- 单分支失败不破坏其他成果；
- 定时触发、重复触发和时区；
- 工作流版本、员工版本和项目配置快照；
- 暂停、恢复、取消和 Worker 中断恢复；
- 预算停止和告警；
- 审批、退回和拒绝；
- 候选经验不会自动写入员工长期记忆；
- V1 不存在自动发布外部平台的路径。

测试顺序为节点样例、完整草稿、历史数据回放、人工触发真实运行、小范围定时运行，最后才开启每日无人值守。

## 11. 验收标准

- 用户可以通过模板创建短视频内容运营工作流；
- 用户可以配置账号定位、项目知识、数量、时间和预算；
- 已发布版本可以每天按项目时区自动启动；
- 工作流可以完成选题、调研、文案、审核和有限返工；
- 所有关键节点交换通过 Schema 验证的 JSON；
- 一个选题失败不会丢失其他成功成果；
- 用户早上可以在控制中心直接审批内容；
- 所有来源、运行日志、审核意见、耗时和费用可追踪；
- Worker 中断后不会丢失已完成节点状态；
- 运行结束后只生成候选经验，不自动修改员工；
- V1 不自动发布内容，也不涉及 EZDSH 自我开发。

## 12. 非目标

- 自动拍摄、剪辑或生成最终视频；
- 自动登录并发布到短视频平台；
- 根据播放数据自动修改员工核心提示词；
- 构建完整的内容资产管理或社交媒体管理平台；
- EZDSH 修改自身或其他项目代码；
- 在 V1 同时覆盖市场、开发、客服等其他行业工作流。
