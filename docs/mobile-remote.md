# 手机浏览器远程控制

EzDSH 内置了一个独立的手机浏览器控制入口。它不会把 DSH Runtime 的回环端口直接暴露到局域网，而是由桌面端启动一个受控的 Mobile Remote 服务，只开放手机端需要的会话接口。

## 局域网配对

1. 启动 EzDSH，打开「设置 → 远程控制」。
2. 确认手机和电脑处于同一个 Wi-Fi，点击「生成配对二维码」。
3. 用手机浏览器扫描二维码。
4. 回到桌面端，在待确认的手机请求旁点击「允许」。
5. 手机会优先打开最近使用的会话；也可以返回会话首页，切换工作区、新建或切换会话。

配对链接有效期为 5 分钟。批准后，浏览器使用 HttpOnly、SameSite Strict Cookie；设备凭据只以哈希形式保存在本机状态目录中。移除设备后，旧 Cookie 立即失效。

## 手机端体验

- 会话首页将工作区、最近会话和新建会话集中在首屏，方便单手操作。
- 对话页为全屏阅读模式：用户消息使用紧凑气泡，助手内容使用完整阅读宽度。
- 思考过程和工具调用会折叠显示；需要排查时可展开输入、输出与执行状态。
- 页面通过服务端事件流持续同步会话进度；断线时会自动尝试读取最新历史。
- 输入区固定在屏幕底部，并会跟随手机键盘的可视区域变化；运行中的会话可直接停止。
- 页面自动跟随手机系统的深色或浅色外观，且支持添加到主屏幕。

## 公网访问

在「公网访问（可选）」中开启后，桌面端会执行：

```text
cloudflared tunnel --url http://127.0.0.1:<mobile-port>
```

这会建立一个临时 HTTPS 地址，不需要路由器端口转发。首次使用前，请按 Cloudflare 文档安装 `cloudflared` 并确保它在系统 `PATH` 中。开启后重新生成二维码，二维码会优先使用公网地址。

临时地址适合测试和短期使用。长期使用建议在可信网络中使用 VPN，或配置固定域名和访问策略的正式隧道；不要把配对二维码或链接转发给他人。

## 安全边界

- DSH Runtime 继续监听 `127.0.0.1`，手机只连接 Mobile Remote 服务。
- 配对必须经过桌面端明确批准。
- 配对挑战 5 分钟过期，设备会话默认 30 天无操作后过期。
- 手机 API 只允许会话列表、工作区读取、历史读取、创建会话、发送任务和取消任务。
- API 检查同源 Origin，响应带有 `X-Content-Type-Options`、`X-Frame-Options` 和 CSP。
- 公网通道关闭后，公网地址立即失效；设备仍保留，重新开启公网访问后需要重新生成配对二维码。
